# Galaxy Link

갤럭시 화면을 맥에서 보고 마우스·키보드로 조작하는 macOS 앱입니다. 한국어 SwiftUI 연결 패널과 별도의 scrcpy 미러링 창으로 구성됩니다. 현재 배포 빌드는 Apple Silicon(M1 이상) · macOS 26 이상을 지원합니다.

## 실행

공유용 DMG에서 앱을 Applications로 복사해 실행합니다. 공유용 앱은 ADB와 영상 라이브러리를 포함하므로 Homebrew가 필요하지 않습니다. 현재 배포본은 Developer ID 공증을 받지 않았으므로 macOS에서 실행 승인이 필요할 수 있습니다.

소스에서 `scripts/build.sh`로 만든 `dist/FoldLink.app`은 로컬 Homebrew 의존성을 사용합니다. 내부 파일명과 번들 식별자는 기존 FoldLink와의 업데이트 호환성을 위해 유지합니다.

1. 갤럭시의 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 눌러 개발자 옵션을 활성화합니다.
2. 개발자 옵션에서 USB 디버깅을 켭니다.
3. 데이터 전송용 USB 케이블로 맥에 연결하고, 휴대폰의 USB 디버깅 허용 팝업을 승인합니다.
4. Galaxy Link의 **유선 연결**에서 기기를 선택하고 **화면 연결**을 누릅니다.

기기가 없거나 인증되지 않았다면 연결 버튼은 비활성화됩니다. 3초마다 목록을 갱신합니다. USB와 무선 디버깅 기기를 모두 표시합니다.

## Wi-Fi 연결

Android 11 이상의 무선 디버깅을 사용합니다. USB 케이블 없이 처음부터 연결할 수 있습니다.

1. 맥과 갤럭시를 같은 Wi-Fi에 연결합니다.
2. 휴대폰의 설정 → 개발자 옵션 → 무선 디버깅을 켜고 해당 메뉴를 엽니다.
3. Galaxy Link의 **무선 연결 → Wi-Fi 연결 설정 / 페어링**을 누릅니다.
4. 휴대폰에서 **페어링 코드로 기기 페어링**을 열고, 표시된 IPv4:포트와 6자리 코드를 앱의 01번 영역에 입력합니다. 휴대폰의 코드 창을 열어 둔 채 **페어링**을 누릅니다.
5. 페어링 후 휴대폰의 코드 창을 닫습니다. 무선 디버깅 첫 화면의 **IP 주소 및 포트**를 앱의 02번 영역에 입력하고 **무선 연결**을 누릅니다. 페어링 포트와 연결 포트는 서로 다릅니다.
6. **완료**로 창을 닫은 뒤 **화면 연결**을 누릅니다.

다음부터는 02번 연결만 진행하면 됩니다. 마지막 연결 주소는 저장하지만, 재부팅이나 네트워크 변경 후에는 포트가 바뀔 수 있습니다. 공유기의 기기 간 통신 차단이나 게스트 Wi-Fi에서는 연결되지 않을 수 있습니다. 코드는 일회성이며 앱의 설정이나 로그에 저장하지 않고 표준입력으로 ADB에 전달합니다.

[Android 공식 무선 디버깅 안내](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi)

## 폴드 접힘·펼침 대응

실제 기본 디스플레이(display 0)를 캡처합니다. 특정 모델의 해상도, 화면 방향, 잘라내기 영역을 고정하지 않습니다. scrcpy가 프레임 크기 변경에 맞춰 영상과 창 비율을 조절하며, 연결 패널에는 엔진이 보고한 전송 해상도를 표시합니다. 해당 수치는 화질 설정에 의해 축소될 수 있습니다. 폴드8 고유 해상도나 물리 힌지 상태를 추정하지 않습니다.

화면을 접으면서 휴대폰이 잠기면 커버 화면을 깨우고 잠금을 해제하세요. 기기에서 커버 화면으로 앱을 이어서 사용하는 설정도 확인하세요. 인코더가 종료되거나 USB 연결이 끊기면 패널에서 다시 연결할 수 있습니다.

### 전환 애니메이션

버전 1.2부터 **실제 scrcpy 영상 창**도 해상도 변경 시 0.36초 동안 부드럽게 크기가 전환됩니다. 전환 중에도 프레임 처리와 터치 입력은 계속됩니다. 빠르게 다시 접으면 현재 창 크기에서 새로운 목표로 이어갑니다. 전체 화면에서는 창 크기 애니메이션을 생략하고 화면에 맞게 표시합니다. macOS 동작 줄이기 설정에서도 즉시 크기를 바꿉니다.

### 앱 아이콘

`Assets/AppIcon.png`는 생성 원본, `Assets/AppIcon.icns`는 macOS 아이콘입니다. 빌드 시 여러 해상도로 패키징하여 앱과 Dock에 적용합니다. 디자인 프롬프트와 생성 방식은 `Assets/IconPrompt.md`에 기록했습니다.

## 한글 입력과 Caps Lock (1.8)

기존에는 한글 조합이 확정될 때마다 클립보드를 변경하고 붙여넣었습니다. 삼성 노트에서 보고된 글자별 줄바꿈·지연을 개선하기 위해 이 경로를 제거했습니다. 현재는 휴대폰의 **Galaxy Link 입력기**가 `InputConnection.commitText()`로 확정 문자열을 직접 전달합니다. 일반 타이핑은 클립보드를 변경하지 않으며, ⌘V/Ctrl+V는 기존 붙여넣기 기능으로 유지합니다.

1. 앱에서 **한글 입력기 설치·설정**을 누릅니다.
2. 휴대폰 설정에서 **Galaxy Link 입력기**를 활성화하고 기본 키보드로 선택합니다. 키보드 사용 안내는 휴대폰에서 직접 확인합니다.
3. 화면을 연결하고 삼성 노트의 텍스트 입력란을 클릭합니다.
4. 사용 후 입력기 하단의 **키보드 변경**을 눌러 삼성 키보드로 돌아갑니다. 연결 종료만으로 휴대폰의 기본 키보드는 자동 변경되지 않습니다.

Caps Lock은 맥의 기존 한·영 전환을 사용합니다. 맥 입력기가 조합을 확정하기 전까지 휴대폰에는 글자가 표시되지 않을 수 있습니다. 입력기는 편집 내용 읽기·저장·네트워크 전송을 하지 않습니다. 외부 텍스트 입력 요청은 ADB shell/root UID에만 허용합니다. 입력기나 입력란이 준비되지 않은 경우 한글을 글자별 붙여넣기로 우회하지 않습니다.

권장 모드를 끄면 기존 UHID 물리 키보드 모드로 연결합니다. 이 모드에서는 휴대폰 측 키보드 배열을 설정해야 합니다.

에뮬레이터 회귀 검증: `python3 scripts/test-ime.py` (emulator-5554 전용). 실제 scrcpy 제어 소켓을 통해 테스트 편집기에 입력하고, 테스트 후 기존 입력기로 복원합니다. 삼성 노트의 편집기별 최종 동작은 실기기에서 별도 확인해야 합니다.

## 조작

- 미러링 창을 클릭해 터치, 드래그해 스와이프합니다.
- 맥 입력기 모드가 기본입니다. Caps Lock으로 맥의 한·영을 전환합니다.
- 오른쪽 Option+F: 전체 화면, 오른쪽 Option+H: 홈, 오른쪽 Option+B: 뒤로 가기.
- 소리·화질·맨 위 표시 설정은 연결 전에 변경합니다.
- 앱 종료 시 해당 앱이 실행한 미러링 프로세스를 종료합니다.

## 빌드와 검증

빌드 전 Xcode Command Line Tools, Homebrew의 `scrcpy`, `android-platform-tools`, `uv`, `pkgconf`, `openjdk`와 Android SDK platform 35 / build-tools 35.0.0이 필요합니다.

```sh
bash scripts/build.sh
bash scripts/test.sh
bash scripts/test-video-window.sh
bash scripts/test-clipboard.sh
```

테스트는 기기 목록과 인증 상태, 접힘·펼침·회전 해상도 로그, 화면 크기 고정을 방지하는 인자를 검증합니다. 실제 폴드8에서 접기→펼치기→회전→다시 접기, 터치 좌표, 한글 입력, 오디오, 케이블 분리 후 재연결은 기기를 연결해 별도로 검증해야 합니다. DRM 보호 콘텐츠는 휴대폰 정책에 따라 검은 화면으로 표시될 수 있습니다.

## 기반 엔진

[scrcpy 공식 프로젝트](https://github.com/Genymobile/scrcpy) · [화면 옵션](https://github.com/Genymobile/scrcpy/blob/master/doc/window.md) · [키보드 설정](https://github.com/Genymobile/scrcpy/blob/master/doc/keyboard.md). scrcpy는 Apache-2.0 라이선스입니다. `vendor/scrcpy-4.1`에 공식 v4.1 소스와 FoldLink 수정 사항을 보관하며, 앱에도 라이선스를 포함합니다. 수정 목록은 `vendor/FOLDLINK-CHANGES.md`에 있습니다.

전용 엔진 빌드에는 uv, pkgconf 및 Homebrew scrcpy 의존성이 필요합니다. Meson과 Ninja는 프로젝트 .build 폴더에 설치합니다. 현재 맥에서 빌드한 앱은 해당 맥의 라이브러리를 참조하며 독립 배포용 패키지는 아닙니다.

## 복사·붙여넣기 (1.3)

영상 창에서 Command+C / Control+C는 선택한 휴대폰 텍스트를 맥 클립보드로 복사하고, Command+V / Control+V는 맥 클립보드 텍스트를 휴대폰에 붙여넣습니다. Command+X / Control+X 잘라내기도 지원합니다. 한글 입력 소스에서도 물리 C/V/X 키 위치를 기준으로 동작합니다.

### 맥 이미지 → 휴대폰

1. 맥에서 이미지를 복사합니다. 클립보드로 복사한 스크린샷, 브라우저의 이미지 복사, Finder의 단일 이미지 파일 복사를 지원합니다.
2. 휴대폰 잠금을 해제하고 이미지 붙여넣기를 지원하는 앱의 입력란을 선택합니다.
3. 영상 창에서 Command+V 또는 Control+V를 누릅니다.

처음에는 `FoldLink 이미지 도우미` APK를 해당 기기에 설치합니다. 네트워크, 사진 보관함, 연락처 권한은 사용하지 않습니다. 앱의 내부 이미지 저장소에는 ADB shell만 쓰기 접근하며, 이미지 클립보드를 붙여넣는 앱은 Android의 임시 URI 읽기 권한으로 접근합니다. 이미지는 PNG로 전달하며 최대 25MB입니다. Mac 이미지 원본은 유지하며 Android URI 문자열로 덮어쓰지 않습니다.

도우미가 잠깐 열려 이미지 클립보드를 등록하고 기존 앱으로 돌아옵니다. 전송 전후 같은 앱이 활성화되어 있을 때만 자동 붙여넣기를 요청합니다. 다른 앱으로 이동했으면 클립보드에만 보관하므로 원하는 위치에서 길게 눌러 붙여넣으세요. 앱이 이미지 클립보드를 지원하지 않으면 입력되지 않습니다. 자동으로 메시지를 전송하지 않습니다.

이미지는 휴대폰 도우미의 내부 저장소에 남으며, 다음 전송 시 24시간이 지난 이미지를 정리합니다. 도우미의 앱 데이터 삭제 또는 제거로 모두 지울 수 있습니다. 이 버전은 맥→휴대폰 이미지 붙여넣기와 양방향 텍스트 클립보드를 지원하며, 휴대폰→맥 이미지 복사는 포함하지 않습니다.

이미지 도우미 소스는 `android-clipboard/`, 빌드는 `scripts/build-clipboard.sh`입니다. Android SDK 35, build-tools 35.0.0, Homebrew OpenJDK를 사용합니다. 개발용 서명 키는 `.build/clipboard/development.keystore`에 보관하므로 업데이트 빌드 시 유지해야 합니다.

## 파일 전송 (1.6)

USB 디버깅을 허용한 뒤 **유선 연결 → 파일 전송 → 파일 열기**를 누르세요. 기기를 선택하고 다운로드·사진·그림 폴더 또는 다른 공유 저장소 하위 폴더를 탐색할 수 있습니다. **맥 → 휴대폰 보내기**에서 여러 파일을 선택하거나, 휴대폰 파일을 선택해 **선택 파일 → 맥 저장**을 누르세요. 원본은 유지되며 같은 이름이 있으면 전송을 중단합니다. 폴더 전체 전송, 보호된 앱 데이터 및 삭제 기능은 지원하지 않습니다. 현재 UI에서는 유선 기기의 파일 전송을 제공합니다.

전송 중에는 창을 닫거나 케이블을 분리하지 마세요. 연결이 끊기면 오류를 표시하며, 휴대폰에 .foldlink-*.part 임시 파일이나 예약한 빈 파일이 남을 수 있습니다. 한 파일당 최대 대기 시간은 1시간입니다.

### 드래그 앤 드롭

파일 전송 창에서 Finder의 파일을 목록으로 끌면 현재 휴대폰 폴더로 복사됩니다. 휴대폰 파일을 선택해 Finder 또는 바탕화면으로 끌면 맥에 저장됩니다. Command/Shift로 여러 파일을 선택할 수 있습니다. 폴더는 더블 클릭해서 열며, 폴더 자체 전송은 지원하지 않습니다. 전송 시 원본은 유지됩니다.

## Galaxy Link 1.7 화면 구성

갤럭시와 맥 연동을 중심으로 무선 연결 / 유선 연결 메뉴를 분리했습니다. 각 메뉴는 해당 연결 방식의 기기를 표시합니다. 파일 전송은 유선 연결 메뉴 안에서 열 수 있습니다. 기존 화면 제어, 소리, 한글 입력, 클립보드, 폴더블 화면 전환 기능은 유지합니다. 업데이트 호환성을 위해 내부 실행 파일과 번들 식별자는 유지합니다.

## 공유용 패키지 생성

```sh
python3 scripts/package-share.py
hdiutil create -volname "Galaxy Link" -srcfolder .build/share-1.8 -ov -format UDZO dist/GalaxyLink-1.8-AppleSilicon.dmg
```

`.build/`와 `dist/`는 Git에 포함하지 않습니다. Android 도우미 업데이트에 사용하는 개발 서명 키도 저장소에 올리지 않습니다.
