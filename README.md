# Galaxy Link

갤럭시를 맥에서 쓰기 위한 앱입니다. 휴대폰 화면을 띄워 마우스와 키보드로 조작하고, 텍스트나 이미지를 붙여넣을 수 있습니다. USB로 연결하면 Finder와 파일을 주고받는 것도 가능합니다.

일반 갤럭시와 폴더블에서 사용할 수 있습니다. 폴드를 접거나 펼치면 맥에 띄운 화면 크기도 따라 바뀝니다.

## 설치

**Apple Silicon 맥(M1 이상), macOS 26 이상**이 필요합니다.

DMG 파일을 열고 앱을 **Applications(응용 프로그램)** 폴더로 옮겨 실행하세요. 배포용 앱에는 필요한 도구가 들어 있어 Homebrew를 따로 설치할 필요가 없습니다.

아직 Apple 공증을 받지 않은 앱이라 처음 실행할 때 macOS에서 차단될 수 있습니다. 이 경우 시스템 설정의 **개인정보 보호 및 보안**에서 실행 허용 여부를 확인해 주세요.

## 처음 연결할 때

먼저 갤럭시에서 개발자 옵션을 켜주세요.

**설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 누르기**

설정 화면으로 돌아오면 아래쪽에 **개발자 옵션**이 생깁니다.

### 유선 연결

1. 개발자 옵션에서 **USB 디버깅**을 켭니다.
2. 데이터 전송이 되는 USB 케이블로 맥과 갤럭시를 연결합니다.
3. 휴대폰에 디버깅 허용 안내가 뜨면 허용합니다.
4. 앱의 **유선 연결**에서 기기를 선택합니다.
5. 아래의 한글 입력 설정을 마친 뒤 **화면 연결**을 누릅니다.

충전만 되는 케이블로는 연결되지 않습니다. 기기가 보이지 않으면 케이블과 휴대폰의 허용 안내부터 확인해 주세요.

### 무선 연결

맥과 갤럭시를 같은 Wi-Fi에 연결해 주세요. 휴대폰은 Android 11 이상이어야 합니다.

1. 개발자 옵션에서 **무선 디버깅**을 켜고 해당 메뉴를 엽니다.
2. 맥 앱에서 **무선 연결 → Wi-Fi 연결 설정 / 페어링**을 누릅니다.
3. 휴대폰의 **페어링 코드로 기기 페어링**을 엽니다. 표시된 주소와 6자리 코드를 맥 앱의 **01번**에 입력하고 페어링합니다.
4. 휴대폰의 페어링 창을 닫습니다. 무선 디버깅 화면에 있는 **IP 주소 및 포트**를 맥 앱의 **02번**에 입력하고 연결합니다.
5. **완료**를 누르고, 한글 입력 설정을 마친 뒤 **화면 연결**을 누릅니다.

**페어링할 때의 포트와 연결할 때의 포트는 다릅니다.** 연결이 안 되면 이 부분을 먼저 확인해 주세요. 다음부터는 보통 02번 연결만 하면 되지만, 포트 번호가 바뀌었다면 새 값을 입력해야 합니다.

## 한글 입력 설정

처음 한 번은 휴대폰에 전용 입력기를 설정해야 합니다.

1. 맥 앱에서 **한글 입력기 설치·설정**을 누릅니다.
2. 휴대폰에서 **Galaxy Link 입력기**를 켜고 기본 키보드로 선택합니다.
3. 화면을 연결한 다음, 휴대폰 앱의 글을 쓸 곳을 클릭합니다.

한·영 전환은 맥에서 쓰던 **Caps Lock**을 그대로 사용합니다. 한글을 조합하는 동안에는 휴대폰에 글자가 조금 늦게 보일 수 있습니다.

사용을 마치면 휴대폰 입력기 아래의 **키보드 변경**을 눌러 삼성 키보드로 돌아갈 수 있습니다. 맥 앱의 연결을 끊는 것만으로는 키보드가 자동으로 바뀌지 않습니다.

1.8에서는 한글을 글자마다 붙여넣던 방식을 바꿨습니다. 한글·영문·엔터를 섞어 입력하는 테스트는 통과했지만, 삼성 노트에서 보고된 줄바꿈과 지연이 해결됐는지는 실기기에서 확인 중입니다.

## 자주 쓰는 조작

| 하고 싶은 일 | 조작 |
| --- | --- |
| 휴대폰 화면 누르기 / 스와이프 | 클릭 / 드래그 |
| 한·영 전환 | Caps Lock |
| 텍스트 복사 / 붙여넣기 / 잘라내기 | ⌘C / ⌘V / ⌘X |
| 전체 화면 | 오른쪽 Option + F |
| 홈 화면 | 오른쪽 Option + H |
| 뒤로 가기 | 오른쪽 Option + B |

복사·붙여넣기는 Control 키로도 됩니다. 단축키는 휴대폰 화면 창을 선택한 상태에서 사용하세요. 소리, 화질, 항상 위에 표시 설정은 화면을 연결하기 전에 바꿀 수 있습니다.

### 이미지 붙여넣기

맥에서 이미지를 복사한 뒤, 휴대폰 앱의 입력란을 클릭하고 **⌘V**를 누르세요. 복사한 스크린샷이나 Finder에서 복사한 이미지 파일도 사용할 수 있습니다.

처음에는 휴대폰에 **FoldLink 이미지 도우미**가 설치됩니다. 잠금이 풀려 있어야 하고, 붙여넣을 앱도 이미지 입력을 지원해야 합니다. 자동으로 붙여넣어지지 않으면 입력란을 길게 눌러 붙여넣어 보세요.

이미지는 PNG 기준 최대 25MB까지 보낼 수 있습니다. 현재 이미지 붙여넣기는 **맥 → 휴대폰**만 지원합니다.

## 파일 주고받기

USB로 연결한 뒤 **유선 연결 → 파일 전송 → 파일 열기**를 누르세요.

- **맥 → 갤럭시:** Finder의 파일을 앱의 파일 목록으로 끌어 놓습니다.
- **갤럭시 → 맥:** 목록의 파일을 Finder나 바탕화면으로 끌어 놓습니다.
- 버튼으로 저장하려면 휴대폰 파일을 먼저 선택한 뒤 **선택 파일 → 맥 저장**을 누르세요. 파일을 선택하기 전에는 버튼이 비활성화되어 있습니다.

Command나 Shift를 누르면 여러 파일을 선택할 수 있습니다. 폴더는 더블 클릭해서 엽니다.

전송은 **복사 방식**이라 원본이 남습니다. 같은 이름의 파일은 덮어쓰지 않습니다. 폴더 통째로 보내기와 앱 전용 보호 폴더 접근은 아직 지원하지 않습니다.

전송 중에는 케이블을 빼거나 창을 닫지 마세요. 연결이 끊기면 휴대폰에 임시 파일이나 빈 파일이 남을 수 있습니다.

## 알아두면 좋은 점

- 폴드를 접으면서 휴대폰이 잠기면 잠금을 풀어주세요. 화면 크기는 자동으로 맞춰집니다.
- 전체 화면이나 macOS의 ‘동작 줄이기’를 사용하는 경우 창 크기 전환 애니메이션은 생략됩니다.
- 일부 동영상처럼 화면 캡처가 제한된 콘텐츠는 검게 보일 수 있습니다.
- 회사나 게스트 Wi-Fi에서는 기기 간 연결이 막혀 무선 연결이 안 될 수 있습니다.
- 이미지 도우미에 남은 이미지는 다음 전송 때 24시간이 지난 것부터 정리합니다. 바로 지우려면 휴대폰에서 도우미의 앱 데이터를 삭제하면 됩니다.

## 직접 빌드하려면

개발 환경 설정, 빌드 명령, 테스트 방법은 [개발 안내](docs/DEVELOPMENT.md)에 모아뒀습니다.

화면 연결은 [scrcpy](https://github.com/Genymobile/scrcpy)를 기반으로 만들었습니다. 사용한 엔진 소스와 Apache-2.0 라이선스는 `vendor/scrcpy-4.1`에, 수정 내역은 [여기](vendor/FOLDLINK-CHANGES.md)에 있습니다.
